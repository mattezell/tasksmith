# Heartbeat

$ARGUMENTS

## Task Types

### daily_briefing
Review completed and failed tasks for recent activity. Check memory logs.
Compile a summary: completed, failed, key decisions, pending items, patterns.

### memory_consolidation
Review recent memory entries. Identify durable facts worth preserving.
Update memory. Remove stale entries. Keep concise.

### health_check
Verify: Claude CLI accessible, disk space, task counts, memory integrity.
Report any issues found.
